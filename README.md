# 🐍 Snake

**Групповая проектная работа по дисциплине «Введение в операционные системы и инструменты разработки».**

Проект представляет собой классическую игру «Змейка» с уникальными возможностями. Игра включает в себя 9 уникальных уровней с прогрессирующей сложностью, систему баффов/дебаффов и уникальную механику смены головы и хвоста.

## 🎮 Управление в игре
Стрелки (Вверх, Вниз, Влево, Вправо) — управление движением змейки.

Пробел — Смена головы и хвоста местами (уникальная механика).

P — Пауза.

Esc — Выход из игры.

## 🧩 Игровые механики
1. Прогрессия уровней (9 уровней)
   Уровни 1-3 (Легкий): Пустое поле. Цель — съесть определенное количество обычной еды.
   Уровни 4-6 (Средний): Появляются статические стены, тупики. Начинают выпадать усложняющие баффы. Цель — больше еды.
   Уровни 7-9 (Сложный): Сложные лабиринты, большое количество стен. Выпадают все виды баффов и дебаффов.

3. Механика смены головы и хвоста
Змейка может мгновенно развернуться, поменяв местами голову и хвост. Это позволяет выбираться из тупиков, но требует аккуратности: в момент разворота направление движения инвертируется.

4. Система баффов (Специальная еда)
С определенным шансом вместо обычной еды выпадает специальная, дающая эффект на 5 секунд:

Помогающие:

🛡️ Неуязвимость (5 сек): Змейка игнорирует столкновения со стенами и собственным хвостом.

🧱 Проход сквозь одну стену: Одноразовый эффект, позволяющий пройти сквозь одну стену без смерти.

🐢 Замедление времени (5 сек): Скорость движения змейки снижается вдвое.

Усложняющие:

⚡ Ускорение (x2): Скорость змейки временно увеличивается в два раза.

🔄 Инверсия управления (5 сек): Стрелки меняют свое значение (Вверх = Вниз, Влево = Вправо). Встречается только на уровнях 7-9.

🌿 Git-история и ветвление
В проекте использовалась модель ветвления Feature Branch Workflow:

main — стабильная версия игры (релизы после слияния веток).

feature/snake-mechanics — разработка логики змейки.

feature/buffs-system — разработка системы еды и баффов.

feature/ui-levels — разработка уровней и интерфейса.

Каждый коммит имеет осмысленное описание (например, feat: add snake swap mechanic, fix: collision with tail bug, docs: update README). Слияние веток производилось через Pull Requests с код-ревью от тимлида.

⚠️ Обработка ошибок и исключительных ситуаций
В программе предусмотрена обработка следующих нештатных ситуаций:

Выход за границы поля: Проверка координат головы змейки на каждом тике. Вывод экрана "Game Over".

Столкновение со стеной или хвостом: Проверка на пересечение координат (если не активен бафф неуязвимости).

Некорректный разворот: Защита от нажатия кнопки «противоположного» направления (нельзя повернуть на 180 градусов без смены головы/хвоста).

Некорректный спавн еды: Проверка, что еда не появляется внутри стены или на теле змейки.

Завершение уровня: Корректный переход на следующий уровень при достижении цели по еде.
